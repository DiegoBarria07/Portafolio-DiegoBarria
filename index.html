Cuadratura Shell IA

Sistema automatizado en Python diseñado para optimizar el cierre de caja en estaciones de servicio. Resuelve la pérdida de tiempo y los errores humanos al realizar el conteo manual de dinero, calculando de forma exacta los descuadres financieros entre el efectivo, tarjetas y aplicaciones.

Para este proyecto diseñé toda la arquitectura lógica, el flujo de usuario y las reglas de validación, utilizando Inteligencia Artificial como herramienta de desarrollo para materializar el código bajo mis especificaciones exactas.
